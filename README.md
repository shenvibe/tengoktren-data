# TengokTren schedule data

Public official Rapid Rail and KTM timetable data for TengokTren. Checks daily at 07:00 Malaysia time using GitHub Actions, without AI. Schedule content commits only when changed. status.json records the most recent successful check. Failed downloads/validation do not publish partial data.

Sources: https://api.data.gov.my/gtfs-static/prasarana?category=rapid-rail-kl and https://api.data.gov.my/gtfs-static/ktmb
